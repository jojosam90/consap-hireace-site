# HireAce — landing site

Static marketing site (no build step): `index.html`, `privacy-policy.html`, `terms-of-service.html`,
and `assets/` (styles, translations in English / 简体中文 / 繁體中文 / Bahasa Melayu, scripts and images).

## Run locally

```
python serve.py          # http://localhost:8000
```

`serve.py` handles clean URLs (`/faq`, `/privacy-policy`, ...) like the live site.
